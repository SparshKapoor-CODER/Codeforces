## ▶️ How to Run a Solution

Every solution reads from standard input and writes to standard output.

```bash
# compile
javac "Div 3/1119/A.java"

# run (type input, or redirect from a file)
java -cp "Div 3/1119" A < input.txt
```

> If a file declares a `package`, run it from the repo root with the package path instead.
